# Monster Hunter Outlanders 海外创作者传播观察

基于公开帖子、公开直播和公开评论样本制作的静态数据看板。

- 区域：LATAM、KR、TWHK、SEA、MEA
- 来源分类：水上、水下、自来水
- 指标：播放量、公开互动量、互动率、内容数量
- 分析：区域／平台／发布阶段／来源分类、传播集中度、内容效果分布、玩家反馈主题
- 来源筛选：传播总览和玩家反馈均可在水上、水下、自来水之间直接切换并显示样本量
- 封面：133 条内容使用已缓存的真实平台缩略图，其余内容显示平台／创作者信息占位封面
- 数据限制：不同平台公开指标口径不完全一致；评论样本不代表全部玩家；趋势按内容发布日期归因，不是历史播放快照

本项目不包含监修状态、内部表格行号、商务条件或审批信息。
